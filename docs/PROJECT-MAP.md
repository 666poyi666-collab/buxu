# WatchIntervals 项目地图

WatchIntervals（步序）是一个产品，手表端、手机端、云同步和 MCP 都在同一个主仓库协作。

```text
WatchIntervals/
├── app/           手表应用
├── phone/         手机伴侣应用
├── cloud/mcp/     Cloudflare 远程 MCP 与云端同步
├── mcp/           旧 Windows 本机兼容 MCP
└── docs/          产品说明、标准和日志
```

`watch-cloud-mcp` 是历史部署仓库，不再作为单独产品。
