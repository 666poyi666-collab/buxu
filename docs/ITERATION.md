# 迭代记录

最近一轮：2026-08-29
版本：Watch 0.23.0（34）／Phone 0.25.1（22）

## 1. 本轮目标

1. 手机端从巨型单体 Activity 重写为 Compose + MVI，把界面、同步编排、权限与计划 CRUD 分离。
2. 在双端建立真正的全局设计系统：颜色、字号、间距、圆角、形状与操作层级集中管理，页面不再内联数值。
3. 重建手机端图标与品牌标志，形成自洽的原创几何体系。
4. 对手表端做同标准的重构与缺陷修复。
5. 校验生产 Cloud MCP，产出 ChatGPT 接入文档，并把云端状态呈现写入手机端。
6. 补齐开发日志、规范、缺陷、迭代与更新日志五类文档。

## 2. 关键决策

**先验证工具链再动手。** 手写 View 体系里 Compose 相关依赖全为 0，因此在写任何 UI 之前先接入 Compose 并跑通 `compileDebugKotlin`，确认 Kotlin 2.0.21 与 AGP 8.7.2 组合可用，避免方案返工。

**保留并复用既有数据层。** `PhonePlanLibrary`、`PhoneSleepRepository`、`WatchConnectionManager`、`CloudSyncCredentials` 等逻辑与传输实现全部原样保留，重写只发生在界面层与状态编排层，把改动面限制在可验证范围内。

**契约层提升为 public 而非绕开。** 这些类原本是 package-private，Kotlin 子包无法访问。选择显式提升契约层可见性，而不是把 UI 代码塞进同一个包。敏感的设备 token 例外：只暴露 `endpoint` 与 `configured()`，另加 `saveEndpointKeepingToken()` 供“只改端点”场景使用，避免把 Keystore 包装的凭据读回界面层。

**可访问性契约化。** 旧测试读取 `MainActivity.java` 源码断言 `dp()` 字面量，既不验证运行时行为，也会因重构误报。改为把描述生成与尺寸下限集中到无 Android 依赖的 `PhoneUiContract`，界面调用契约、测试断言契约，界面此后可自由重构。

**手表端走增量重构。** `Ui.java` 与四个 Activity 是已完成校准的 378×496 仪表盘，全量重写风险高于收益。因此保持 `Ui` 作为门面，把令牌下移到 `WatchTokens`，只修真实缺陷与裸色值。

## 3. 完成项

### 手机端

- `MainActivity` 重写为 Kotlin Compose 宿主，只保留生命周期、系统栏、权限与跨页跳转。
- 新增 `PhoneViewModel` 单一状态持有者，收敛为 `PhoneUiState`；四阶段同步编排、计划 CRUD、5 秒轮询、控制命令、睡眠加载与云端配置全部在此，IO 在单并发作用域串行。
- 新增四个页面：计划（列表/详情/编辑器三级密封路由）、训练（活动环与按状态推导的操作）、历史、睡眠。
- 设计系统：`PhoneTheme`、`PhoneDimens`、`PhoneIcons`（14 个原创图标）、`PhoneComponents`、`PhoneUiContract`。
- 新增连接与云同步设置浮层，显示云端状态徽章与链路说明。
- 图表用 Compose Canvas 重写：活动环、近 7 晚趋势、阶段时间线、阶段构成条，保留全部数据真实性约束。
- IPv4/IPv6 DNS 同时提供，避免 Node 17+ 默认 IPv6 偏好导致验证失败。

### 手表端

- 新增 `WatchTokens` 集中设计令牌；`Ui` 常量改为转发，既有调用点不变。
- 12 处内联裸色值替换为语义令牌。
- `WorkoutService.Snapshot` 新增 `stageKind`，训练页改用 `Stage.Kind` 枚举判断阶段强调色。

### 品牌图标

- 自适应前景、单色层与传统层共用同一“间歇路线”几何：两段阶梯式往返阶段汇入一枚前进箭头。
- 折返转弯改用整数半径圆弧，传统层按 4/9 等比缩放，双端 pathData 逐字一致。

### 云端

- 只读校验生产 Worker：`/healthz`、`/readyz`、RFC 9728 受保护资源元数据与 AS 元数据全部正常，未授权访问正确返回 401。
- 新增《Cloud MCP 与 ChatGPT 接入》文档，含实测结果、20 个工具清单与故障排查。

## 5. 遗留与后续

1. **手表端底部安全区仍未处理。** 当前 0 处 `WindowInsets` 消费，378×496 页面上最后一项内容可能被系统 UI 遮挡。本轮优先完成了令牌与缺陷修复，安全区需要配合真机截图逐页调整，列为下一轮首项。

3. **BUG-062 依赖环境变更。** 仓库路径含非 ASCII 字符导致单元测试无法加载，当前在 ASCII 路径工作树执行测试；彻底解决需移动仓库位置。
4. **BUG-003 与 BUG-005 仍为 Open。** 局域网明文 HTTP 与关键路径吞异常属于既有技术债，未进入本轮范围。
5. **`Ui.java` 未做文件级拆分。** 令牌已集中，但 800 行的组件与自绘视图仍未按职责切分，可在下一轮配合安全区改造一并处理。
